# JSON-Based Character Data - Migration Guide

## Why JSON Instead of ScriptableObject?

For a VTT, JSON is the better choice:

✅ **Portable**: Players can import from D&D Beyond, Roll20, Foundry VTT, etc.  
✅ **Version Control**: Easy to diff and track changes in Git  
✅ **Human Readable**: Can edit in any text editor  
✅ **Shareable**: Easy to share character files between players  
✅ **Tool Integration**: Can be generated by external character builders  
✅ **No Unity Required**: Can create/edit characters outside Unity  
✅ **Type-Safe Skills**: Uses enum-based skills (no typos!)

## What Changed

### New Components

1. **`DnD5eSkill` Enum** - Type-safe skill enumeration (18 skills)
   - No more string typos!
   - IntelliSense support
   - Compile-time checking

2. **`DnD5eCharacterData`** - Complete 5e character model
   - All standard 5e fields
   - Calculated properties (modifiers, proficiency bonus)
   - Backward compatible with old `CharacterData`

3. **`PlayerDataJsonLoader`** - JSON file loader
   - Loads from `StreamingAssets/Characters/`
   - Can save/load character files
   - Uses Unity's JsonUtility

### File Structure

```
Assets/
├── StreamingAssets/
```

## How to Use

### 1. Create a Character JSON File

Create a file in `Assets/StreamingAssets/Characters/YourCharacter.json`:

```json
{
    "characterName": "Arlen",
    "level": 3,
    "characterClass": "Fighter",
    "race": "Human",
    "background": "Soldier",
    "strength": 16,
    "dexterity": 14,
    "constitution": 14,
    "intelligence": 10,
    "wisdom": 12,
    "charisma": 8,
    "maxHitPoints": 28,
    "currentHitPoints": 28,
    "armorClass": 16,
    "proficientSavingThrows": ["STR", "CON"],
    "_proficientSkillsStrings": ["Athletics", "Intimidation", "Perception", "Survival"],
    "proficientArmor": ["Light", "Medium", "Heavy", "Shields"],
    "proficientWeapons": ["Simple", "Martial"]
}
```

### 2. Load in Code

```csharp
// Load from file
var characterData = PlayerDataJsonLoader.LoadFromFile("Characters/YourCharacter.json");

// Or load from JSON string
string json = "...";
var characterData = PlayerDataJsonLoader.LoadFromJson(json);

// Use the data
int strengthMod = characterData.strengthModifier;
int athleticsMod = characterData.GetSkillModifier(DnD5eSkill.Athletics);
```

### 3. Update Service to Use JSON

Update `LocalPlayerDataService` or create a new `JsonPlayerDataService`:

```csharp
public class JsonPlayerDataService : IPlayerDataService
{
    private DnD5eCharacterData _characterData;
    
    public JsonPlayerDataService(string jsonFilePath)
    {
        _characterData = PlayerDataJsonLoader.LoadFromFile(jsonFilePath);
        if (_characterData == null)
        {
            _characterData = new DnD5eCharacterData(); // Fallback to defaults
        }
    }
    
    public CharacterData GetPlayerData()
    {
        // Convert to legacy format for backward compatibility
        return _characterData.ToLegacyCharacterData();
    }
    
    // ... rest of interface implementation
}
```

## Skill Enum Usage

### Type-Safe Skills

```csharp
// ✅ Good - Compile-time checked
var skill = DnD5eSkill.Athletics;
int modifier = characterData.GetSkillModifier(skill);
bool isProficient = characterData.IsProficientInSkill(skill);

// ✅ Good - Display name
string displayName = skill.GetDisplayName(); // "Athletics"
string ability = skill.GetAbilityScore(); // "STR"

// ❌ Bad - No more string typos!
// var skill = "Athletcs"; // Typo would cause bugs
```

### Converting from Strings (Backward Compatibility)

```csharp
// Convert string to enum
var skill = DnD5eSkillExtensions.FromString("Athletics");
if (skill.HasValue)
{
    int modifier = characterData.GetSkillModifier(skill.Value);
}
```

## Complete 5e Fields Available

The new `DnD5eCharacterData` includes:

- ✅ Basic Info (name, level, class, race, background)
- ✅ Ability Scores (all 6)
- ✅ Combat Stats (HP, AC, speed, initiative, hit dice)
- ✅ Proficiencies (saving throws, skills, armor, weapons, tools, languages)
- ✅ Calculated Values (modifiers, proficiency bonus)
- ✅ Other (inspiration, exhaustion, conditions, death saves)

## Backward Compatibility

The old `CharacterData` class still works! The new system can convert:

```csharp
// New → Old
var legacy = dnD5eData.ToLegacyCharacterData();

// Old code continues to work
var service = PlayerDataServiceLocator.Service;
var data = service.GetPlayerData(); // Returns CharacterData
```
