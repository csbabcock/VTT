# D&D 5e Character Data Model - Design

## Why JSON over ScriptableObject?

For a VTT, JSON is better because:
- ✅ **Portable**: Players can import from D&D Beyond, Roll20, etc.
- ✅ **Version Control**: Easy to diff and track changes
- ✅ **Human Readable**: Can edit in any text editor
- ✅ **Shareable**: Easy to share character files
- ✅ **Tool Integration**: Can be generated by external tools
- ✅ **No Unity Required**: Can create/edit characters outside Unity

## Complete 5e Character Sheet Elements

### Basic Info
- Name, Level, Class, Subclass, Race, Subrace, Background
- Alignment, Player Name, Experience Points

### Ability Scores
- Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma
- Ability Score Improvements (ASIs)

### Skills (18 total - use enum)
- Acrobatics, Animal Handling, Arcana, Athletics, Deception, History
- Insight, Intimidation, Investigation, Medicine, Nature, Perception
- Performance, Persuasion, Religion, Sleight of Hand, Stealth, Survival

### Combat Stats
- Hit Points (current/max/temp)
- Armor Class
- Initiative
- Speed (walking, flying, swimming, climbing)
- Hit Dice (current/max)

### Proficiencies
- Saving Throws (STR, DEX, CON, INT, WIS, CHA)
- Skills (list of enum values)
- Armor (Light, Medium, Heavy, Shields)
- Weapons (Simple, Martial, specific weapons)
- Tools (list)
- Languages (list)

### Equipment
- Weapons (with attack/damage stats)
- Armor (with AC calculation)
- Items/Inventory
- Currency

### Features & Traits
- Class Features
- Racial Traits
- Feats
- Background Features

### Spells (if spellcaster)
- Spell Slots (by level)
- Known/Prepared Spells
- Spell Save DC
- Spell Attack Bonus

### Other
- Inspiration
- Exhaustion
- Conditions
- Death Saves
